# Chart values

The defaults are in [values.yaml](../charts/wishalia/values.yaml).

| Value                                                                                 | Default                                       | Description                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hosts.public`                                                                        | `wishalia.example.com`                        | Host of the public view (share links).                                                                                                                                                                                  |
| `hosts.app`                                                                           | `app.wishalia.example.com`                    | Host of the management app. Must differ from `hosts.public`.                                                                                                                                                            |
| `hosts.api`                                                                           | `""`                                          | Host of the REST API v1, e.g. `api.wishalia.example.com`. Empty: the API v1 is off. The ingress forwards `/v1` only.                                                                                                    |
| `apiV1.rateLimit`                                                                     | `120`                                         | Requests a minute and per token, per API replica.                                                                                                                                                                       |
| `apiV1.allowFrom`                                                                     | the `ingress-nginx` namespace                 | NetworkPolicy peers allowed to reach the API when `hosts.api` is set: the ingress controller.                                                                                                                           |
| `config.appName`                                                                      | `Wishalia`                                    | Product name shown to people.                                                                                                                                                                                           |
| `config.logLevel`                                                                     | `info`                                        | Log level of the API.                                                                                                                                                                                                   |
| `auth.ownerEmails`                                                                    | `""`                                          | Emails allowed to create their account by themselves (the owners), comma-separated.                                                                                                                                     |
| `auth.cookieDomain`                                                                   | `""`                                          | Parent domain of the two hosts, for one session on both. Defaults to `hosts.public` when `hosts.app` is under it; `-` keeps the session on the app host.                                                                |
| `auth.oidc.issuer`, `auth.oidc.clientId`                                              | `""`                                          | OIDC provider of the owners (`OIDC_CLIENT_SECRET` goes in `existingSecret`). Shows a sign-in button in the management app.                                                                                              |
| `auth.oidc.name`                                                                      | `SSO`                                         | The provider's name on that button: « Se connecter avec … ».                                                                                                                                                            |
| `auth.mailFrom`                                                                       | `""`                                          | Sender of the magic links (`SMTP_URL` goes in `existingSecret`).                                                                                                                                                        |
| `existingSecret`                                                                      | `""`                                          | Secret loaded as environment variables by every component.                                                                                                                                                              |
| `image.registry` / `image.repository`                                                 | `ghcr.io` / `arcanexus/wishalia`              | The images are `<registry>/<repository>-<component>:<tag>`.                                                                                                                                                             |
| `image.tag`                                                                           | appVersion                                    | Tag of the four images.                                                                                                                                                                                                 |
| `api`, `worker`, `webApp`, `webPublic`                                                | enabled, 1 replica                            | `enabled`, `replicas`, `port`, `resources` and extra `env` of each component.                                                                                                                                           |
| `postgresql.enabled`                                                                  | `true`                                        | Deploys PostgreSQL with the chart (StatefulSet, official `postgres` image) and gives the API and the worker its `DATABASE_URL`. `false`: your own database, see `externalDatabase`.                                     |
| `postgresql.image.*`                                                                  | `docker.io/library/postgres:18-alpine`        | `registry`, `repository`, `tag` and `pullPolicy` of the built-in PostgreSQL. A new major version needs a dump and a restore.                                                                                            |
| `postgresql.auth.database`, `postgresql.auth.username`                                | `wishalia`                                    | Database and user made at the first start: lowercase letters, digits and `_`.                                                                                                                                           |
| `postgresql.auth.existingSecret`                                                      | `""`                                          | Secret holding the password (key `postgresql.auth.passwordKey`, `password`). Empty: made at the first install and kept. Required with ArgoCD or `helm template`.                                                        |
| `postgresql.persistence.*`                                                            | enabled, `5Gi`                                | `enabled`, `size`, `storageClass` (empty: the default class; `-`: none) and `accessModes` of its volume, kept on uninstall. Off: the data is lost with the pod.                                                         |
| `postgresql.resources`, `postgresql.podSecurityContext`, `postgresql.securityContext` | non-root 70, read-only root                   | Resources and security of the PostgreSQL pod (uid 70 is `postgres` in the Alpine image).                                                                                                                                |
| `externalDatabase.existingSecret`                                                     | `""`                                          | With `postgresql.enabled=false`: the Secret holding your database's full URL. Empty: `DATABASE_URL` comes from `existingSecret`.                                                                                        |
| `externalDatabase.urlKey`                                                             | `DATABASE_URL`                                | The key of that URL in the Secret (e.g. `uri` for CloudNativePG).                                                                                                                                                       |
| `migrations.enabled`                                                                  | `true`                                        | Applies the migrations (`node dist/migrate.js` in the API image). Your own database: a Job before each install and upgrade (Helm hook). The built-in PostgreSQL: an init container of each API pod, which waits for it. |
| `ingress.enabled`                                                                     | `false`                                       | Ingress with one rule per host, to `web-public` and `web-app`. The API is never exposed.                                                                                                                                |
| `ingress.className`, `ingress.annotations`, `ingress.tls`                             |                                               | Usual Ingress settings.                                                                                                                                                                                                 |
| `networkPolicy.enabled`                                                               | `true`                                        | Only the frontends may reach the API (and `apiV1.allowFrom` when `hosts.api` is set), and the worker accepts no traffic, except the metrics scrape from `metrics.allowFrom`.                                            |
| `metrics.enabled`                                                                     | `true`                                        | Prometheus `/metrics` on every component, on `metrics.port` (9464), published by the Services under the port name `metrics`, never by the ingress. See [Monitoring](monitoring.md).                                     |
| `metrics.allowFrom`                                                                   | the `monitoring` namespace                    | NetworkPolicy peers allowed to scrape the API and the worker when `networkPolicy.enabled`.                                                                                                                              |
| `metrics.serviceMonitor.enabled`                                                      | `false`                                       | Creates a ServiceMonitor (Prometheus Operator). `interval` (30s), `scrapeTimeout` (10s) and extra `labels`.                                                                                                             |
| `podSecurityContext`, `securityContext`                                               | non-root 10001, read-only root, no capability | Hardened by default.                                                                                                                                                                                                    |
| `startupProbe`, `livenessProbe`, `readinessProbe`                                     |                                               | Timings of the probes on `/healthz` (`/readyz` for the API readiness).                                                                                                                                                  |
| `nodeSelector`, `tolerations`, `affinity`, `podAnnotations`, `podLabels`              |                                               | Scheduling and metadata of every pod.                                                                                                                                                                                   |
