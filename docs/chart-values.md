# Chart values

The defaults are in [values.yaml](../charts/wishalia/values.yaml).

| Value                                                                                 | Default                                       | Description                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hosts.public`                                                                        | `wishalia.example.com`                        | Host of the public view (share links).                                                                                                                                                                                                                                                                                                                                            |
| `hosts.app`                                                                           | `app.wishalia.example.com`                    | Host of the management app. Must differ from `hosts.public`.                                                                                                                                                                                                                                                                                                                      |
| `hosts.api`                                                                           | `""`                                          | Host of the REST API v1, e.g. `api.wishalia.example.com`. Empty: the API v1 is off. The ingress forwards `/v1` only.                                                                                                                                                                                                                                                              |
| `apiV1.rateLimit`                                                                     | `120`                                         | Requests a minute and per token, per API replica.                                                                                                                                                                                                                                                                                                                                 |
| `apiV1.allowFrom`                                                                     | the `ingress-nginx` namespace                 | NetworkPolicy peers allowed to reach the API when `hosts.api` is set: the ingress controller.                                                                                                                                                                                                                                                                                     |
| `config.appName`                                                                      | `Wishalia`                                    | Product name shown to people.                                                                                                                                                                                                                                                                                                                                                     |
| `config.defaultLocale`                                                                | `fr`                                          | Language for a reader whose browser asks for none the product speaks (`fr` or `en`). Each person can still choose theirs in the settings.                                                                                                                                                                                                                                         |
| `config.logLevel`                                                                     | `info`                                        | Log level of the API.                                                                                                                                                                                                                                                                                                                                                             |
| `config.helpUrl`                                                                      | `""`                                          | Where the help link at the foot of every page leads (an `https` address). Empty: the [user guide](user-guide.md) of the project's wiki, in the page's language.                                                                                                                                                                                                                   |
| `auth.ownerEmails`                                                                    | `""`                                          | Emails allowed to create their account by themselves (the owners), comma-separated.                                                                                                                                                                                                                                                                                               |
| `auth.cookieDomain`                                                                   | `""`                                          | Parent domain of the two hosts, for one session on both. Defaults to `hosts.public` when `hosts.app` is under it; `-` keeps the session on the app host.                                                                                                                                                                                                                          |
| `auth.oidc.issuer`, `auth.oidc.clientId`                                              | `""`                                          | OIDC provider of the owners (`OIDC_CLIENT_SECRET` goes in `existingSecret`). Shows a sign-in button in the management app.                                                                                                                                                                                                                                                        |
| `auth.oidc.name`                                                                      | `SSO`                                         | The provider's name on that button: « Se connecter avec … ».                                                                                                                                                                                                                                                                                                                      |
| `auth.mailFrom`                                                                       | `""`                                          | Sender of the magic links (`SMTP_URL` goes in `existingSecret`).                                                                                                                                                                                                                                                                                                                  |
| `existingSecret`                                                                      | `""`                                          | Secret loaded as environment variables by every component.                                                                                                                                                                                                                                                                                                                        |
| `image.registry` / `image.repository`                                                 | `ghcr.io` / `arcanexus/wishalia`              | The images are `<registry>/<repository>-<component>:<tag>`.                                                                                                                                                                                                                                                                                                                       |
| `image.tag`                                                                           | appVersion                                    | Tag of the four images.                                                                                                                                                                                                                                                                                                                                                           |
| `images.enabled`                                                                      | `false`                                       | Images of the items ([Images](images.md)): deploys imgproxy (internal only) and gives the components the volume or the bucket. Needs `existingSecret` with `IMGPROXY_KEY`, `IMGPROXY_SALT` (and `S3_ACCESS_KEY`, `S3_SECRET_KEY` with `s3`).                                                                                                                                      |
| `images.storage`                                                                      | `volume`                                      | Where the files live: `volume` (a PersistentVolumeClaim) or `s3`. See [Images](images.md#where-the-files-live).                                                                                                                                                                                                                                                                   |
| `images.persistence.existingClaim`                                                    | `""`                                          | With `volume`: your PersistentVolumeClaim. Empty: the chart creates `<release>-images`, kept on `helm uninstall`.                                                                                                                                                                                                                                                                 |
| `images.persistence.size`, `storageClass`, `accessModes`, `annotations`               | `5Gi`, `""`, `[ReadWriteOnce]`, `{}`          | The claim the chart creates (empty class: the cluster's default). With `ReadWriteOnce`, the API, the worker and imgproxy are kept on one node, unless `affinity` is set.                                                                                                                                                                                                          |
| `images.cleanup.intervalHours`, `images.cleanup.graceHours`                           | `6`, `24`                                     | The worker removes the files no image names any more, every `intervalHours` (`0`: never), once older than `graceHours`. See [Images](images.md#unused-files).                                                                                                                                                                                                                     |
| `images.s3.endpoint`, `images.s3.region`, `images.s3.bucket`                          | `""`, `us-east-1`, `wishalia`                 | With `s3`: the bucket (MinIO), e.g. `http://minio.storage.svc:9000`. The endpoint is then required.                                                                                                                                                                                                                                                                               |
| `images.garage.enabled`                                                               | `false`                                       | With `images.storage: s3` and no `images.s3.endpoint`: deploys [Garage](https://garagehq.deuxfleurs.fr), one node, inside the cluster only, as the bucket. Needs `GARAGE_RPC_SECRET` and a key in Garage's format in `existingSecret`. See [Images](images.md).                                                                                                                   |
| `images.garage.image`                                                                 | `dxflrs/garage:v2.6.0`                        | Garage's image (`repository`, `tag`, `pullPolicy`).                                                                                                                                                                                                                                                                                                                               |
| `images.garage.persistence.*`                                                         | `10Gi`                                        | `existingClaim`, `size`, `storageClass` (`-`: none) and `accessModes` of its volume, kept on uninstall.                                                                                                                                                                                                                                                                           |
| `images.garage.resources`                                                             |                                               | Resources of the Garage pod.                                                                                                                                                                                                                                                                                                                                                      |
| `images.garage.ui.enabled`                                                            | `false`                                       | Deploys [Garage UI](https://github.com/Noooste/garage-ui), a web console for the chart's Garage. Needs `GARAGE_ADMIN_TOKEN` in `existingSecret`. See [Images](images.md#its-console-garage-ui).                                                                                                                                                                                   |
| `images.garage.ui.image`                                                              | `noooste/garage-ui:v0.14.0`                   | The console's image (`repository`, `tag`, `pullPolicy`).                                                                                                                                                                                                                                                                                                                          |
| `images.garage.ui.host`, `images.garage.ui.tlsSecretName`                             | `""`                                          | Its own host on the ingress (with `ingress.className` and `ingress.annotations`) and its TLS secret. Empty: no ingress, `kubectl port-forward`.                                                                                                                                                                                                                                   |
| `images.garage.ui.oidc.*`                                                             | off                                           | `enabled`, `issuer`, `clientId`, `name`, `scopes` (`[openid, profile, email]`): sign-in with your provider (needs `host`, `GARAGE_UI_OIDC_CLIENT_SECRET` in `existingSecret`). Off: sign-in with the admin token.                                                                                                                                                                 |
| `images.garage.ui.env`                                                                | `{}`                                          | Extra `GARAGE_UI_*` variables of the console. With OIDC, set who may sign in: `GARAGE_UI_AUTH_OIDC_ROLE_ATTRIBUTE_PATH` (the claim, e.g. `groups`) and `GARAGE_UI_AUTH_OIDC_ADMIN_ROLES` (comma-separated), or the console will not start.                                                                                                                                        |
| `images.garage.ui.resources`                                                          |                                               | Resources of the console.                                                                                                                                                                                                                                                                                                                                                         |
| `images.uploadLimit`                                                                  | `12M`                                         | Largest form of the management app (`BODY_SIZE_LIMIT`): an image sent is 10 MB at most. With images off, the limit is `3M`, for the imported lists.                                                                                                                                                                                                                               |
| `images.imgproxy.image`                                                               | `ghcr.io/imgproxy/imgproxy:v4.0.25`           | imgproxy's image (`repository`, `tag`, `pullPolicy`).                                                                                                                                                                                                                                                                                                                             |
| `images.imgproxy.replicas`, `port`, `resources`, `env`                                | 1, `8080`                                     | imgproxy's Deployment. It reads only the image files, signed paths only, and only the two frontends may reach it when `networkPolicy.enabled`.                                                                                                                                                                                                                                    |
| `images.imgproxy.maxSrcResolution`                                                    | `50`                                          | Largest image imgproxy reads, in megapixels.                                                                                                                                                                                                                                                                                                                                      |
| `api`, `worker`, `webApp`, `webPublic`                                                | enabled, 1 replica                            | `enabled`, `replicas`, `port`, `resources` and extra `env` of each component.                                                                                                                                                                                                                                                                                                     |
| `postgresql.enabled`                                                                  | `true`                                        | Deploys PostgreSQL with the chart (StatefulSet, official `postgres` image) and gives the API and the worker its `DATABASE_URL`. `false`: your own database, see `externalDatabase`.                                                                                                                                                                                               |
| `postgresql.image.*`                                                                  | `docker.io/library/postgres:19-alpine`        | `registry`, `repository`, `tag` and `pullPolicy` of the built-in PostgreSQL. The tag starts with its major version (`19-alpine`).                                                                                                                                                                                                                                                 |
| `postgresql.upgrade.enabled`                                                          | `true`                                        | A new major version of `postgresql.image` dumps the data of `fromImage`'s version and restores it, once ([Upgrading PostgreSQL](installation.md#upgrading-postgresql)). Off: a new major version starts empty.                                                                                                                                                                    |
| `postgresql.upgrade.fromImage.*`                                                      | `docker.io/library/postgres:18-alpine`        | The image of the previous major version, which reads its data folder (`registry`, `repository`, `tag`, `pullPolicy`).                                                                                                                                                                                                                                                             |
| `postgresql.auth.database`, `postgresql.auth.username`                                | `wishalia`                                    | Database and user made at the first start: lowercase letters, digits and `_`.                                                                                                                                                                                                                                                                                                     |
| `postgresql.auth.existingSecret`                                                      | `""`                                          | Secret holding the password (key `postgresql.auth.passwordKey`, `password`). Empty: made at the first install and kept. Required with ArgoCD or `helm template`.                                                                                                                                                                                                                  |
| `postgresql.persistence.*`                                                            | enabled, `5Gi`                                | `enabled`, `size`, `storageClass` (empty: the default class; `-`: none) and `accessModes` of its volume, kept on uninstall. `existingClaim`: use a PersistentVolumeClaim you already have instead. Off: the data is lost with the pod.                                                                                                                                            |
| `postgresql.resources`, `postgresql.podSecurityContext`, `postgresql.securityContext` | non-root 70, read-only root                   | Resources and security of the PostgreSQL pod (uid 70 is `postgres` in the Alpine image).                                                                                                                                                                                                                                                                                          |
| `externalDatabase.existingSecret`                                                     | `""`                                          | With `postgresql.enabled=false`: the Secret holding your database's full URL. Empty: `DATABASE_URL` comes from `existingSecret`.                                                                                                                                                                                                                                                  |
| `externalDatabase.urlKey`                                                             | `DATABASE_URL`                                | The key of that URL in the Secret (e.g. `uri` for CloudNativePG).                                                                                                                                                                                                                                                                                                                 |
| `migrations.enabled`                                                                  | `true`                                        | Applies the migrations (`node dist/migrate.js` in the API image). Your own database: a Job before each install and upgrade (Helm hook). The built-in PostgreSQL: an init container of each API pod, which waits for it.                                                                                                                                                           |
| `ingress.enabled`                                                                     | `false`                                       | Ingress with one rule per host, to `web-public` and `web-app`. The API is never exposed.                                                                                                                                                                                                                                                                                          |
| `ingress.className`, `ingress.annotations`, `ingress.tls`                             |                                               | Usual Ingress settings.                                                                                                                                                                                                                                                                                                                                                           |
| `networkPolicy.enabled`                                                               | `true`                                        | Only the frontends may reach the API (and `apiV1.allowFrom` when `hosts.api` is set), and the worker accepts no traffic, except the metrics scrape from `metrics.allowFrom`.                                                                                                                                                                                                      |
| `metrics.enabled`                                                                     | `true`                                        | Prometheus `/metrics` on every component, on `metrics.port` (9464), published by the Services under the port name `metrics`, never by the ingress. See [Monitoring](monitoring.md).                                                                                                                                                                                               |
| `metrics.allowFrom`                                                                   | the `monitoring` namespace                    | NetworkPolicy peers allowed to scrape the API and the worker when `networkPolicy.enabled`.                                                                                                                                                                                                                                                                                        |
| `metrics.serviceMonitor.enabled`                                                      | `false`                                       | Creates a ServiceMonitor (Prometheus Operator). `interval` (30s), `scrapeTimeout` (10s) and extra `labels`.                                                                                                                                                                                                                                                                       |
| `podSecurityContext`, `securityContext`                                               | non-root 10001, read-only root, no capability | Hardened by default.                                                                                                                                                                                                                                                                                                                                                              |
| `volumePermissions.enabled`                                                           | `false`                                       | For volume drivers that do not apply `fsGroup` (NFS through csi-driver-nfs, hostPath): an init container, root with the `CHOWN` capability only, gives the root folder of the PostgreSQL, image and Garage volumes to the pod's user (70 for PostgreSQL, 10001 otherwise). Needs an NFS export without root squash. `image` (`docker.io/library/busybox:1.38.0`) and `resources`. |
| `startupProbe`, `livenessProbe`, `readinessProbe`                                     |                                               | Timings of the probes on `/healthz` (`/readyz` for the API readiness).                                                                                                                                                                                                                                                                                                            |
| `nodeSelector`, `tolerations`, `affinity`, `podAnnotations`, `podLabels`              |                                               | Scheduling and metadata of every pod.                                                                                                                                                                                                                                                                                                                                             |
