# Security policy

Wishalia keeps a family's secrets: who gives what, and how much. The owner of a list must never
learn it before they choose to, and nobody outside the family must read the lists. A leak of
contributions to the owner is treated as a security bug.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/Arcanexus/wishalia/security/advisories/new)
instead. You will get an answer as soon as possible.

## Supported versions

Only the latest release receives security fixes.

The security model is described in [docs/security.md](docs/security.md).
